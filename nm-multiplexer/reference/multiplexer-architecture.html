Glossary

PTYPseudoterminal: a pair of virtual character devices forming a bidirectional channel. pty(7)
MasterThe PTY end the server reads/writes (*os.File from pty.Start).
SlaveThe PTY end that behaves exactly like a classical terminal; the shell's stdin/stdout/stderr.
Line disciplineKernel TTY layer between master and slave: echo, line editing, signal characters. Åkesson
Cooked / rawCooked (canonical): line-buffered with editing. Raw: bytes passed through immediately, uninterpreted.
ServerLong-lived process holding all state: shells, PTYs, output.
ClientShort-lived process bridging one real terminal to the server over a socket.
Attach / detachStart / end a client connection. Detach never ends the shell.
SIGWINCHWindow-change signal the TTY sends the foreground job when its size is set.
SIGHUPHangup signal sent to a whole session when its terminal goes away; why shells die without a multiplexer.
FramingSplitting a byte stream into typed messages (e.g. data vs resize). Needed once control messages exist.
