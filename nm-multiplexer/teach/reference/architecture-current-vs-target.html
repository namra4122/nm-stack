A4. The byte path over time

sequenceDiagram
  participant K as terminal (raw)
  participant C as nmux-client
  participant M as PTY master
  participant L as line discipline
  participant B as bash
  K->>C: keystroke byte (no local echo)
  C->>M: io.Copy(nmux, os.Stdin)
  M->>L: byte
  L->>B: byte on slave stdin
  B->>L: output
  L->>M: output + echo
  M->>C: io.Copy(os.Stdout, nmux)
  C->>K: bytes to screen
  Note over K,C: window resized
  K-->>C: SIGWINCH
  C->>M: InheritSize (read stdin size, set master size)
  L-->>B: SIGWINCH to foreground job

  • The fd is passed with SCM_RIGHTS (compat/imsg-buffer.c:798). The server keeps it as c->fd (server-client.c:3094).
  • MSG_RESIZE has no payload. If it has data, the server rejects it (server-client.c:2833). The server reads the size itself with ioctl(c->fd, TIOCGWINSZ) (tty.c:138).
